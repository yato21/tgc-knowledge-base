# TG-KB: база знаний Telegram-канала

Сбор, хранение и гибридный поиск по постам любого открытого Telegram-канала
(парсер веб-превью t.me/s, без API-ключей). Канал указывается аргументом команды.

## Команды

- Доступные каналы: `ls data/*_posts.jsonl` — имя файла без `_posts.jsonl` = имя канала.
- Поиск: `python3 tools/kb_search.py <канал> "<запрос>" --json` — машинный режим;
  без `--json` — человекочитаемый.
- Полный пост: прочитай файл `data/posts/<канал>/<id>.md` целиком — каждый пост отдельный файл.
- Состояние базы: `python3 tools/kb_search.py <канал> x --doctor`.
- Докачка новых постов: `python3 tools/tg_channel_parser.py <канал> update`.
- Сбор канала с нуля: `python3 tools/tg_channel_parser.py <канал> backfill`.

## Правила поиска

1. Формулируй 2–3 варианта запроса: русский и английский, термин и концепт, синонимы.
2. Точные токены (названия, идентификаторы, цены) — `--mode keyword`; смысловые запросы — гибрид (по умолчанию).
3. Перед ответом открой пост-файл найденного хита целиком.
4. Указывай url для каждого утверждения.
5. Если после всех вариантов ничего не найдено — сообщи об этом, не выдумывай.
6. JSON-ответ с ключами `error`/`hint` — данные, а не сбой: действуй по `hint`. Предупреждения на stderr — не сбой.
7. Для регуляторных и ценовых вопросов предпочитай свежие посты и указывай дату.
8. Коды выхода: 0 — есть хиты, 1 — пусто, 2 — ошибка.
