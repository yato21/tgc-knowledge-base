## База знаний TG-канала (инструмент tg-kb)

Сбор, хранение и гибридный поиск по постам любого открытого Telegram-канала — канал
указывается аргументом команды (парсер веб-превью t.me/s, без API-ключей).

- Доступные каналы: `ls data/*_posts.jsonl` — имя файла без `_posts.jsonl` = имя канала.
- Поиск: `python3 tools/kb_search.py <канал> "<запрос>" --json` — машинный режим; без `--json` — человекочитаемый.
- Полный пост: прочитай файл `data/posts/<канал>/<id>.md` целиком — каждый пост отдельный файл.
- Состояние базы: `python3 tools/kb_search.py <канал> x --doctor`.
- Докачка новых постов: `python3 tools/tg_channel_parser.py <канал> update`.
- Сбор канала с нуля: `python3 tools/tg_channel_parser.py <канал> backfill`.

Правила поиска:
- Формулируй 2–3 варианта запроса: русский и английский, термин и концепт, синонимы.
- Точные токены (названия, идентификаторы, цены) — `--mode keyword`; смысловые запросы — гибрид (по умолчанию).
- Перед ответом открой пост-файл найденного хита целиком.
- Указывай url для каждого утверждения.
- Если после всех вариантов ничего не найдено — сообщи об этом, не выдумывай.
- JSON-ответ с ключами `error`/`hint` — данные, а не сбой: действуй по `hint`. Предупреждения на stderr — не сбой.
- Для регуляторных и ценовых вопросов предпочитай свежие посты и указывай дату.
- Коды выхода: 0 — есть хиты, 1 — пусто, 2 — ошибка.

Опционально: русский стемминг вендоризован в `tools/_vendor/snowballstemmer/` (BSD-3-Clause) —
работает с любым python3 без установки пакетов. Без него поиск деградирует до raw-токенов
(предупреждение на stderr, не сбой).
